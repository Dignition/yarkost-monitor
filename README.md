# ЯркостьМонитор

Управление яркостью всех мониторов из трея Windows в стиле Windows 11.

## Возможности

- Общий ползунок — меняет яркость на всех мониторах сразу, плюс отдельный ползунок на каждый монитор.
- При запуске читает текущую яркость каждого монитора (ничего не сбрасывает).
- Плавное анимированное изменение яркости (отключается в настройках).
- Профили: сохраняются текущие значения всех мониторов, переключение мгновенно по Ctrl+Alt+1..9 (слот назначается профилю).
- Автозапуск с Windows (переключатель в настройках).
- Внешние мониторы — по DDC/CI, встроенный экран ноутбука — по WMI.

## Установка (себе и кому угодно)

Дважды кликните **`make_installer.bat`** — получите один файл
`installer_output\YarkostMonitor-Setup.exe`. Запустите его сами и/или
скиньте кому угодно: на другом компьютере не нужен Python — обычный
мастер установки на русском, программа появляется в «Пуске» и
«Параметры → Приложения», автозапуск включается сам, удаляется штатно.

Скрипт сам собирает exe (PyInstaller) и компилирует установщик (Inno Setup;
при отсутствии поставит его через winget).

## Запуск из исходников (для разработки)

```
pip install -r requirements.txt
python main.py
```

Для запуска без окна консоли: `pythonw main.py`.

## Использование

- Клик по иконке-солнцу в трее — окно с ползунками.
- Кнопка «+» — сохранить текущие значения как профиль и назначить хоткей.
- Шестерёнка — настройки: автозапуск, плавность, скорость, переименование/удаление профилей и смена слотов.
- Кнопка обновления — пересканировать мониторы (после подключения/отключения).

## Если монитор не найден

Включите DDC/CI в экранном меню самого монитора (обычно в разделе
«Настройки» / «Прочее»). Через некоторые док-станции и переходники
DDC/CI не проходит — подключайте монитор напрямую HDMI/DisplayPort.

## Файлы

- `main.py` — запуск, трей, связка всего
- `flyout.py` — всплывающее окно у трея
- `settings_dialog.py` — окно настроек и диалог нового профиля
- `monitors.py` — потоки управления мониторами (DDC/CI + WMI)
- `hotkeys.py` — глобальные хоткеи Ctrl+Alt+1..9
- `config.py` — настройки и профили (хранятся в `%APPDATA%\YarkostMonitor\config.json`)
- `make_installer.bat` + `setup.iss` — сборка распространяемого `YarkostMonitor-Setup-<версия>.exe`
- `LICENSE` — полный текст GNU GPL v3 (лицензия собственного кода)
- `LICENSE_SUMMARY_RU.txt` — краткое информационное пояснение (страница в установщике)
- `THIRD_PARTY_NOTICES.md` + `licenses/` — сторонние компоненты и тексты их лицензий
- `SOURCE_CODE.md` — как получить исходный код конкретной версии и собрать её
- `requirements.lock.txt` — точные версии зависимостей релиза
- `icon.ico` — иконка приложения

## Требования

Windows 10 (64-bit) или Windows 11.

## Публикация релиза на GitHub

1. Создайте репозиторий на github.com (кнопка «New repository»),
   лицензию при создании не добавляйте — она уже есть в проекте.
2. В папке проекта выполните:

```
git init
git add .
git commit -m "Yarkost Monitor 1.0.0"
git branch -M main
git tag v1.0.0
git remote add origin https://github.com/Dignition/yarkost-monitor.git
git push -u origin main --tags
```

3. Соберите установщик (`make_installer.bat`) и приложите
   `installer_output\YarkostMonitor-Setup-1.0.0.exe` к релизу
   (Releases → Draft a new release → тег `v1.0.0`); архив исходников
   GitHub добавит автоматически.
4. Проверьте из браузера без входа в аккаунт, что страница релиза и
   исходники доступны. До этого установщик распространять нельзя.

Версия должна совпадать в `config.py` (`APP_VERSION`), `setup.iss`
(`MyAppVersion`), имени установщика и git-теге. Папки сборки (`dist`,
`build`, `installer_output`) в репозиторий не попадают — они исключены
в `.gitignore`.
